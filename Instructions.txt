
## Termux-X11

A simple, messy way to run a fully functional xfce desktop in Termux-X11.

I am not a security expert so I'm sure it will get some critisism but for the amount of time I've spent messing around with QEMU, ISOs, VMs and VNC clients, it is worth sharing for a beginner to play around with.

## Prerequisites ##

# Install Termux and Termux-X11 from Google play or thier official Github repositories.

Termux
https://github.com/termux/termux-app/releases

Termux-11
https://github.com/termux/termux-x11/releases

# Install updates and initialize x11-repo (assuming you have a fresh Termux installation)... And yes, I prefer apt over pkg.

apt update && apt upgrade -y

apt install x11-repo termux-x11

# Install a desktop environment (this is based on xfce, I am sure it can be modified to use other environments but I have not tried any).

apt install xfce4 xfce4-goodies

# Install a web browser of your choice.

apt install firefox

apt install chromium

# Install whatever else you want to run.

apt install gedit vlc gimp

# Create a script to launch your desktop environment in the Termux-X11 app.

nano start-x11.sh

# Paste this inside the file.

#############

#!bin/bash
termux-x11 :1 -xstartup "dbus-launch --exit-with-session xfce4-session" &
clear
echo .
echo .
echo "Switch to X11 to access your desktop."
echo

##############

# Now make the script executable.

chmod +x start-x11.sh

# Now give it a try!

./start-x11.sh

## Things to keep in mind ##
This could be much better. I plan to improve it over time but for now, it does the trick.





# Enjoy your fully functional, on-demand XFCE desktop! That is actually usable!!
